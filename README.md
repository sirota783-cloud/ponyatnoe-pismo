# Понятное письмо — версия 4

Версия 4 не зависит от встроенного AI или переводчика Chrome.

## Как работает

1. Пользователь загружает PDF или фотографию.
2. Браузер отправляет документ на сервер приложения.
3. Сервер передаёт документ в OpenAI Responses API.
4. Для PDF модель получает и текст, и изображения страниц.
5. Модель возвращает структурированный результат:
   - кто прислал письмо;
   - что это за письмо;
   - требуется ли действие;
   - личный срок;
   - требуется ли оплата сейчас;
   - простое объяснение;
   - важные пункты;
   - пошаговые действия;
   - полный перевод;
   - места, где модель не уверена.

## Запуск локально

Требуется Python 3.10+.

```bash
pip install -r requirements.txt
```

Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="ваш_ключ"
uvicorn app:app --reload
```

Открыть:

http://127.0.0.1:8000

## Render

1. Загрузить папку проекта в GitHub.
2. В Render создать новый **Web Service** из этого репозитория.
3. Render может использовать `render.yaml`.
4. В Environment добавить секрет:
   `OPENAI_API_KEY`
5. После Deploy открыть адрес Render.

Ключ API хранится только на сервере. Его нельзя вставлять в `index.html`.

## Модель

По умолчанию:

`gpt-5.6-terra`

Можно заменить переменной окружения `OPENAI_MODEL`.

## Конфиденциальность

Приложение само не сохраняет документ после выполнения запроса.
Для анализа документ передаётся OpenAI API.
Временный OpenAI File ID для PDF удаляется после завершения запроса (best effort).

## Ограничения прототипа

- Максимальный файл: 20 МБ.
- Форматы: PDF, JPG, PNG, WEBP, GIF.
- Это объяснение документа, а не юридическая, медицинская или финансовая консультация.
